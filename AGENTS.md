# Ringo

Ringo is a Flutter workspace. It currently contains a clean application shell
at `apps/ringo` and shared, domain-neutral utility packages.

## Flutter

Use the version pinned by FVM for Flutter commands:

```bash
fvm flutter <command>
```

## Workspace

```bash
melos bootstrap
```

Run the application from `apps/ringo`:

```bash
fvm flutter run
```
